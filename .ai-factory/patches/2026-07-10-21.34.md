# Preserve Mini App delta colors and legacy page sizes

**Date:** 2026-07-10 21:34
**Files:** frontend/src/components/miniapp/LeaderboardDetailView.tsx, frontend/src/hooks/usePaginationParams.ts, frontend/src/components/tables/PaginationControls.tsx, frontend/src/types/index.ts
**Severity:** high

## Problem

The Mini App delta to the previous event always rendered in the default Telegram
text color instead of green or red. In addition, valid bookmarked URLs such as
`?page_size=75` were silently changed to a 50-item page after adding the `all`
page-size option.

## Root Cause

`Metric` always added `tg-title`, whose unlayered CSS rule sets a text color and
overrides Tailwind's layered success/error utilities. The pagination type was
narrowed to only `50 | 100 | 'all'`, and normalization mapped every in-range
number except 100 to 50 despite the backend accepting the whole 50–100 range.

## Solution

Apply `tg-title` only when a metric has no explicit color class. Keep `PageSize`
numeric for valid legacy values, preserve an in-range value from the URL, and
render that value as a temporary select option alongside the standard
50/100/All choices.

## Prevention

- When combining project theme classes with Tailwind color utilities, verify
  which rule wins in the cascade.
- Preserve documented URL/API values when introducing a smaller set of UI
  options.
- Keep a regression test for valid non-default page sizes such as 75.
