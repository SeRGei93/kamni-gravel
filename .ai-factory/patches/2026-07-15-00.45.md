# Сохранение настройки показа получателей при создании события

**Дата:** 2026-07-15 00:45
**Файлы:** `frontend/src/app/(dashboard)/events/page.tsx`
**Серьёзность:** medium

## Проблема

При создании события включённая настройка `show_gift_recipients` не попадала
в запрос API, поэтому всегда сохранялось безопасное значение `false`.

## Корневая причина

Страница создания вручную собирает `CreateEventRequest` из данных формы и не
переносила новое поле переключателя в этот объект.

## Решение

В `createData` добавлен `show_gift_recipients` из данных формы. Логирование и
автоматический тест не добавлены: текущий утверждённый план для этой функции
требует ручную проверку и запрещает новые runtime-логи.

## Предотвращение

- При добавлении поля в форму проверять все адаптеры payload между компонентом и API-клиентом.
- Для будущих изменений формы покрывать построение create-payload регрессионным тестом, если это допускает план.
