# Show automatic gift recipients to gift owners

**Date:** 2026-07-16 09:16
**Files:** backend/internal/application/query/get_manual_gifts.go, backend/internal/application/query/get_manual_gifts_test.go, backend/internal/application/dto/manual_gift.go, backend/internal/infrastructure/http/handler/gifts.go, backend/internal/infrastructure/http/handler/miniapp.go, backend/internal/infrastructure/http/handler/miniapp_test.go, backend/internal/infrastructure/http/server.go, frontend/src/app/(miniapp)/miniapp/my-gifts/page.tsx, frontend/src/components/miniapp/MyGiftCard.tsx, frontend/src/components/miniapp/MyGiftCard.test.tsx, frontend/src/types/index.ts
**Severity:** medium

## Problem

The Mini App "My Prizes" tab did not show recipients for automatically
distributed gifts even when the event setting `show_gift_recipients` was
enabled. Manually assigned recipients remained visible.

## Root Cause

The event setting had previously been wired only into the manual-recipient
component and was later removed from that path so gift owners could always
manage manual assignments. The automatic card branch never rendered a
recipient, and the protected owner read model loaded only the persisted
`manual_recipient_participant_id`; calculated automatic prize assignments were
not included in the response.

## Solution

The owner query now optionally enriches automatic gifts from the existing
prize-distribution handler when `show_gift_recipients` is enabled. It returns a
privacy-safe recipient list per gift, including multi-slot gifts with more than
one recipient, without exposing Telegram user IDs. The Mini App card renders
that list only for automatic gifts while keeping manual recipients visible
regardless of the event setting. Structured logs use the
`[FIX:auto-gift-recipients]` prefix.

## Prevention

- Trace visibility settings through session data, protected API read models,
  and every relevant UI branch.
- Reuse the canonical prize-distribution query instead of duplicating matching
  rules in the Mini App.
- Cover both enabled and disabled visibility states, multi-recipient automatic
  gifts, and the independent manual-recipient behavior.
